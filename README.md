# QuestGaze

QuestGaze is a cloud-based, auto-scaling architecture for real-time data processing, utilizing a distributed data processing platform.

QuestGaze is aimed at developers who need a straightforward, dependable solution.

- QuestGaze is a cloud-based, auto-scaling

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/QuestGaze.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

QuestGaze is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
